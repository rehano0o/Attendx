# AttendX

### Smart Campus Attendance Management System

AttendX is a mobile-first campus management application designed to simplify everyday academic activities for students, teachers, and administrators.

## 📱 Download AttendX

The latest Android APK is available from the official AttendX release.

**[Download AttendX for Android](YOUR_APK_DOWNLOAD_LINK)**

### Installation

1. Download the AttendX APK.
2. Open the downloaded APK on your Android device.
3. If Android asks for permission to install apps from this source, allow it.
4. Tap **Install**.
5. Open AttendX and sign in with your account.

> **Note:** AttendX is currently distributed as an Android APK for testing and deployment. Google Play Store distribution may be added later.

## ✨ Features

### Attendance
- Secure attendance sessions
- Rotating attendance codes
- Location-based verification
- Student attendance records
- Teacher attendance management

### Assignments
- Teachers can create assignments
- Students can submit files
- Teachers can review submissions
- Grading and submission status

### Academic Management
- Student and teacher accounts
- Class management
- Academic records
- Attendance tracking
- Reports

### 👥 User Roles

**Admin**
- Manage users
- Manage classes
- Manage academic data

**Teacher**
- Manage classes
- Conduct attendance
- Create assignments
- Review and grade submissions

**Student**
- Mark attendance
- View attendance
- Submit assignments
- View academic information
